# CodeCoach AI — For Educators

**A free, open-source coding platform your students will actually use.**

## What is it?

CodeCoach AI is a LeetCode-style practice platform with built-in AI coaching — designed for university students across all majors. Students solve coding problems and learn programming languages (C, Python, Java) with instant, context-aware AI feedback.

## Why recommend it to your class?

| | CodeCoach AI |
|---|---|
| **Cost** | Free — students bring their own NVIDIA API key for AI coaching, no subscription |
| **Curriculum alignment** | 100 DSA questions + language curricula mapped to standard CS topics |
| **Languages** | Python, JavaScript, Java — starter code for every question |
| **AI coaching** | Hint, Review, Explain, Debug modes — like a TA available 24/7 |
| **Privacy** | No ads, no data selling, student data is minimal and protected |
| **Open source** | Fully auditable — the code is public on GitHub |

## How students use it

1. Sign up with email/password (Google OAuth coming soon)
2. Browse 100+ coding questions or start a language curriculum
3. Write code in the editor (Monaco), run it, submit against test cases
4. Ask the AI coach for hints, reviews, or explanations
5. Track their own progress — no grade book, no pressure

## Privacy & Academic Integrity

- Students authenticate with email/password — no university SSO required
- Submission history is stored locally per account; no class rosters or grade data
- Rate limits prevent API abuse
- Full privacy policy available at `/privacy`
- No ads, no tracking, no third-party data sharing

## Roadmap

- **Phase 1** — DSA question bank (100 questions, 14 topics) — *current*
- **Phase 2** — C, Python, Java curricula with interleaved lessons + exercises
- **Phase 3** — DBMS/SQL, OOP, Web Development modules

## Getting started for educators

1. Direct students to the platform URL
2. They create an account and optionally add a free NVIDIA API key for AI coaching
3. No setup, no roster upload, no IT overhead
